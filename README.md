# 一秒钟，计算机到底能做多少事？

用 [Remotion](https://www.remotion.dev/) 纯代码绘制的竖屏科普动画（1080×1920，30fps，约 2 分 15 秒）。
画面里的每一个元素（时钟、电子管、芯片、晶体管网格、地球、数据中心、分形、星系……）都是用
SVG / Canvas / CSS 现场绘制的，没有使用任何图片或视频素材；配乐与音效也由脚本逐帧合成，
所有冲击音效都与画面帧精确对齐。

## 叙事结构：一路升级

| # | 场景 | 每秒运算量 | 视觉 |
|---|------|-----------|------|
| 1 | 开场：1 秒有多长 | — | 1 秒精确扫完的光环、眨眼、故障风标题 |
| 2 | 你·心算 | 10⁰ | 霓虹人像，一道题 1 秒 |
| 3 | 1946 · ENIAC | 5×10³ | 电子管墙逐个点亮，5,000 个粒子飞出排成方阵 |
| 4 | 1971 · Intel 4004 | 9.2×10⁴ | DIP 芯片推进到晶圆电路，92,000 格指令网格被扫描填满（ENIAC 只占左上角一小块） |
| 5 | 现代 CPU | ~10¹¹ | 示波器上的时钟从 1 Hz 加速到 5 GHz；光绕地球 7.5 圈 vs 一个时钟周期只走 6 厘米；16 核流水线 |
| 6 | CPU 眼中的时间 | — | 时间隧道：读内存=8 分钟、读硬盘=6 天、眨眼=47 年、1 秒=158 年 |
| 7 | AI 芯片 | 10¹⁵ | 16,896 核心阵列的波纹；实时计算的曼德博集合百万倍深度缩放 |
| 8 | 超级计算机 | 1.7×10¹⁸ | 3D 机房飞越；数字逐级砸出：1700 → 170 万 → … → 170 亿亿 |
| 9 | 终章 | — | 80 亿人要算 6 年多；一个人要算 540 亿年（宇宙年龄近 4 倍）；静默——1 秒。 |

贯穿全片的左侧「每秒运算次数」对数标尺（10⁰ → 10¹⁸）随每个时代上涨；
背景星空的速度、配色、鼓点速度（70 → 150 BPM）也同步逐级升级。

## 使用

```bash
npm install
npm run audio        # 生成 public/soundtrack.wav（合成配乐，约 15 秒；render 前会自动执行）
npm run dev          # Remotion Studio 预览
npm run render       # 输出 out/one-second.mp4
```

`node scripts/stills.mjs <输出目录> <帧号...>` 可批量渲染静帧并拼成联系表，方便检查画面。

## 数据说明

- 眨眼约 0.3 秒；简单心算按每秒 1 题计。
- ENIAC（1946）：每秒 5,000 次加法，17,468 根电子管，约 27 吨，占地约 167 m²，功耗约 150 kW。
- Intel 4004（1971）：2,300 个晶体管，每秒约 9.2 万条指令。
- 现代桌面 CPU：主频约 5 GHz（一个周期 0.2 ns，光在其中走约 6 cm），16 核、每周期多条指令 → 每秒数千亿条指令（量级估算）。
- 延迟：内存约 100 ns、固态硬盘随机读约 100 µs（按 5 GHz 放大到「1 周期 = 1 秒」换算）。
- 顶级 AI 芯片：以 H100 为例，16,896 个 FP32 核心，BF16 稠密算力约 10¹⁵ 次/秒。
- 顶级 E 级超算：以 El Capitan 为例，约 4.4 万块 APU，HPL 实测超过 1.7×10¹⁸ 次浮点运算/秒。
- 1.7×10¹⁸ ÷ 80 亿人 ≈ 2.1×10⁸ 秒 ≈ 6.7 年；1.7×10¹⁸ 秒 ≈ 539 亿年 ≈ 宇宙年龄（138 亿年）的 3.9 倍。
